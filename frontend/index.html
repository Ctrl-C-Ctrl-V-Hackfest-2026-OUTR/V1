    How it works

    Three passes over the name. That's the whole trick.

    Every domain goes through the same pipeline, in this order. Nothing leaves the machine.

    01 · Normalise

    Clean the input

    Strip the protocol, path and www. Decode punycode so xn-- labels show their real characters. Split off the suffix, including Indian ones like .co.in and .gov.in.

    https://www.xn--pple-43d.com/id → аpple.com (Cyrillic а)
    02 · Rules + ML

    Score the name

    Rules compare the name with the watched brands: fake letters, one-typo edits, brands inside longer names or subdomains, risky endings, scam words.

    03 · Verdict + evidence

    Show why

    Every verdict shows the signals behind it, and a list can be scored at once.

    The page is using its built-in browser engine right now: rules only, with different cut-offs (70 and 40). Run python server.py in the HACKFEST folder to switch to the full engine with the ML model.
